#### 🚀 已上线 · Shipping

**[Palio 帕小助](https://palio.site)** — an AI co-pilot for *Palworld*, in EN / 中文 / 日本語
> Not another lookup table. A hand-rolled **agentic tool loop** (`search_pals` / `get_habitat` /
> `breeding_lookup` / `status_lookup`) grounds every answer in scraped game data instead of letting
> the model hallucinate place names. Next.js 16 App Router · path-based i18n · Supabase (RLS + magic
> link) · Stripe checkout + webhook fulfilment · Vercel.

**[Ship Before You Code](https://vickyhoo.gumroad.com/l/yezjh)** — a workflow handbook for AI coding
> The premise: the leverage isn't in *writing* the code, it's in the research, validation and design
> you do **before** the first line. Written from real sessions, not theory.

#### 💼 工作时 · Building at work

Commercial products, so no repos to link — but this is the problem space I spend my days in:

**Mensura** — ask business questions in plain language, get governed answers
> Built on one rule: **no agent ever writes SQL.** Agents can only call named, pre-defined
> metrics, which keeps every answer reviewable and every number the one the business agreed on.

**Tender** — let AI agents run DevOps inside a network they can't reach
> Agents get **named tools, not a shell** — the difference between passing a compliance
> review and failing one. Writes go through human approval.
