#### 🔭 How I approach AI engineering

I'm interested in the boundary between **what a model is allowed to decide** and **what the
system is allowed to do**. For anything going to production I'd rather build:

```text
Model
  ↓  explicit tools, never raw access
Validation / Permissions
  ↓  human approval where the blast radius is real
Real-world action
```

…than hand an agent an open shell and a database password.
